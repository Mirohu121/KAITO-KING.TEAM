# 試合フロー整理 — 実装指示書

対象: プログラマー  
前提シーン: `Assets/Scenes/TestField.unity`  
関連: `Documentation/Combat_Alpha_Spec.md`

---

## 0. 制約（必須）

- UI は **Canvas Prefab**（`Assets/UI/Prefabs/`）。コードで UI を組まない
- 入力は **Input System**。`Input.GetAxis` 等に戻さない
- `RobotPrefab` の A/B/C **移動ステ数値は変更しない**
- Robogee エディタメニューを増やさない
- 勝敗時の演出に **`Time.timeScale` を 0 付近で放置しない**（必ず復帰パスを用意）

---

## 1. 現状とゴール

### 現状
- タイトル画面は無い
- Play → 機体選択 → 1v1 → 勝敗テキスト表示まで
- 終了後の `timeScale` 復帰・再戦導線が弱い

### ゴール
1. 一時停止（ポーズ）
2. 試合終了後の二択導線
3. 相手機体の選択（可能なら同PR、難しければ続チケット）

---

## 2. 一時停止（ポーズ）

### 仕様
- **タイトルは作らない**
- **機体選択画面**および**試合中**で `Esc`（既存 `ToggleCursor` / 必要なら Pause Action）でポーズ
- ポーズ中: `Time.timeScale = 0` 可。ただし解除で必ず `1` に戻す
- ポーズ UI は Prefab（例: `PauseHud.prefab`）+ Binder

### ポーズメニュー案（最小）

| ボタン | 動作 |
|--------|------|
| 再開 | ポーズ解除、試合 / 選択に戻る |
| 機体選択に戻る | 試合を破棄し選択画面へ（試合中のみでも可） |
| やめる | 下記「やめる」と同じ |

機体選択中の Esc は「再開 / やめる」だけでも可。

### 完了条件
- [ ] 選択画面で Esc → ポーズ UI → 再開できる
- [ ] 試合中で Esc → ポーズ UI → 再開できる
- [ ] ポーズ解除後、入力・タイマー・NPC が正常

---

## 3. 試合終了フロー

### 仕様
試合終了（コア破壊 or タイムオーバー）後、結果表示の下（または全面）に **二択**:

| ボタン | 動作 |
|--------|------|
| **機体選択に戻る** | `timeScale = 1`。試合オブジェクト（プレイヤー/NPC/Match HUD）を片付け、機体選択 UI を再表示 |
| **やめる** | `timeScale = 1`。Play 終了に相当する挙動（Editor なら Play 停止でよい。ビルドならアプリ終了 or 「終了しました」表示まで。チームで1つ決めて実装） |

### 実装メモ
- `CombatMatchController` の終了処理で `timeScale` を落としているなら、終了 UI 表示前/表示時に **必ず復帰経路**を持つ
- 「機体選択に戻る」はシーンリロードでも、Bootstrap の再初期化でも可。どちらか一方に統一し、仕様に明記する

### 完了条件
- [ ] 勝敗後に二択が出る
- [ ] 「機体選択に戻る」で選択からやり直せる（燃料HUD等が選択中に出ないこと）
- [ ] 「やめる」で timeScale が 1 のまま残り続けない
- [ ] 連戦してもオブジェクトが増え続けない（リーク無し）

---

## 4. 相手機体の選択（推奨・同梱希望）

### 仕様
機体選択を **2ステップ** または **同一画面の2欄** にする。

例 A（わかりやすい）:
1. 「自分の機体」→ A/B/C
2. 「相手の機体」→ A/B/C → 試合開始

例 B（同一画面）:
- 左: 自機 A/B/C
- 右: 敵 A/B/C
- 「開始」ボタン

- 表示ラベルは **A / B / C** のみでよい
- 敵は選んだ Prefab をスポーン（オレンジ等で識別は現状踏襲可）
- NPC 脳（`NpcChaseBrain`）は敵側に付与

### 完了条件
- [ ] 自機・敵機をそれぞれ A/B/C で選べる
- [ ] 選んだ組み合わせで 1v1 が始まる
- [ ] Prefab ステ数値は未変更

## 5. Prefab / スクリプト想定（参考・強制ではない）

| 用途 | 例 |
|------|-----|
| ポーズ UI | `Assets/UI/Prefabs/PauseHud.prefab` + `PauseHudBinder` |
| 終了 UI | `Assets/UI/Prefabs/ResultHud.prefab`（既存 MatchHud の Result 拡張でも可） |
| 選択拡張 | 既存 `UnitSelectHud` を編集（Binder 拡張） |
| フロー制御 | `CombatAlphaBootstrap` / `CombatMatchController` |

UI 担当が Prefab を触れる状態を維持すること。

---

## 6. テスト手順（提出前）

1. Play → 機体選択（自機・敵機）→ 試合開始
2. 試合中 Esc → 再開
3. 試合を勝敗まで進める → 「機体選択に戻る」→ 再選択 → 再試合
4. 再度勝敗 → 「やめる」
5. 選択画面でも Esc ポーズが破綻しないこと

---

## 7. やらないこと（スコープ外）

- ネット対戦
- 部位破壊の本実装
- A/B/C 移動パラメータの調整
